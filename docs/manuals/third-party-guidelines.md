# サードパーティ素材・ライブラリの取り扱いガイドライン

このプロジェクトで使用するサードパーティ製のソフトウェア・フォント・アセット類に関するルールをまとめます。

---

## 1. 管理ファイル

リポジトリルートの [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) が一覧です。  
サードパーティのものを追加・変更・削除するたびに、このファイルを必ず更新してください。

---

## 2. 追加前のチェック

新しいサードパーティ素材を追加する前に、以下を確認します。

### 受け入れ可能なライセンス

| ライセンス | 商用利用 | 備考 |
|---|---|---|
| MIT | ○ | 表示義務あり |
| Apache 2.0 | ○ | 表示義務あり、特許条項あり |
| BSD-2-Clause / BSD-3-Clause | ○ | 表示義務あり |
| OFL-1.1 (SIL Open Font License) | ○ | フォント専用。単体販売禁止 |
| CC0-1.0 | ○ | パブリックドメイン相当。表示不要 |
| CC-BY-4.0 | ○ | 著作者表示が必要 |

### 要個別確認のライセンス

| ライセンス | 理由 |
|---|---|
| GPL v2 / v3 | コードのコピーレフト感染リスクがある。使用箇所の隔離を検討 |
| LGPL | 動的リンクなら許容される場合があるが要確認 |
| CC-BY-SA 4.0 | 派生物への同一ライセンス要求がある |
| 独自・商用ライセンス | 個別に条文を精査する |

### 追加禁止のライセンス

| ライセンス | 理由 |
|---|---|
| CC-NC (非商用のみ) | 商用ゲームへの組み込みが禁止されている |
| CC-ND (改変禁止) | 必要な改変が行えない |

## 3. THIRD_PARTY_NOTICES.md への記載方法

以下のフォーマットで追記してください。

```markdown
## [素材名]

- **Type**: Font / Library / Asset / Texture / Sound / etc.
- **Source**: https://...
- **License**: ライセンス名 (SPDX識別子)
- **License URL**: https://...

### Copyright

```
著作権表示をここに verbatim（そのまま）コピー
```

### [ライセンス名]

```
ライセンス全文、またはライセンス全文が長い場合はライセンスURLへの参照
```
```

## 4. OFL-1.1 フォントの特別ルール

現在使用中: **WDXL Lubrifont JP N**

OFL-1.1 で配布されているフォントには以下の制約があります。

| 行為 | 可否 |
|---|---|
| ゲームへのバンドル（埋め込み）| ○ 可能 |
| ゲームと一緒に配布 | ○ 可能。ただし著作権表示とライセンスの同梱が必要 |
| フォントファイル単体での販売 | ✕ 禁止 |
| フォントの改変 | ○ 可能。ただし Reserved Font Name の使用禁止 |
| 改変フォントを別ライセンスで配布 | ✕ 禁止（OFL のまま配布すること） |
| 改変フォントに著作者名を使った宣伝 | ✕ 禁止（明示的な書面による許可がある場合を除く） |

> **Reserved Font Name** とは、OFL 配布物の著作権表示の後に指定されているフォント名のことです。  
> 改変バージョンでは、この名前をプライマリフォント名として使用することができません。

## 5. 配布時の義務

ゲームをビルドしてパッケージ化する際は、`THIRD_PARTY_NOTICES.md` を必ずパッケージに含めてください。

- Steam・App Store などへのリリースビルド
- 社内テスト配布ビルド
- ベータ・プレイテストビルド

いずれの場合も `THIRD_PARTY_NOTICES.md` の同梱が必要です。

---

## 6. よくあるケース

### フォントを追加したい

1. Google Fonts などで「License」を確認する。OFL-1.1 や Apache 2.0 であれば追加可能。
2. フォントファイルを `Content/` 以下の適切なフォルダへ配置する。
3. `THIRD_PARTY_NOTICES.md` に著作権表示とライセンス全文を追加する。

### ライブラリ（C++ / Blueprint）を追加したい

1. リポジトリの README やライセンスファイルでライセンスを確認する。
2. GPL 系の場合は特に注意。プロジェクトリードに相談する。
3. `THIRD_PARTY_NOTICES.md` に追記する。

### アセット（テクスチャ・サウンド・モデル）を追加したい

1. 購入・ダウンロード元の利用規約を確認する。商用ゲームへの組み込みが明示的に許可されているか確認。
2. Fab (旧 Unreal Marketplace) のアセットは Fab EULA に従う（`THIRD_PARTY_NOTICES.md` への記載は任意だが推奨）。
3. CC-NC や ND が付いているアセットは使用禁止。

---

## 7. 不明な場合

ライセンスの解釈に迷ったときはプロジェクトリードに確認してください。  
判断を保留したまま追加しないこと。
